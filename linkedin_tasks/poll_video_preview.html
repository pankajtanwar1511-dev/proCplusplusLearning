✅ Answer: Data race = UB; RC = logic bug
Data race = undefined program. Race condition = wrong program.

• Data race: a property of memory accesses. TSan can catch it.
• Race condition: a property of the algorithm. Every access may be legal.
• Race condition, no data race: if (stock.load() > 0) stock.fetch_sub(1);
• Data race, no race condition: two threads store true to a plain bool done. Still UB.

❌ "A kind of RC": a data race can exist where the logic does not depend on order at all.
❌ "std::atomic fixes both": atomics remove data races, not check-then-act races.
❌ "Only on ARM": a data race is UB by the C++ rules on any hardware.

💡 Data-race-free is the minimum bar for a defined program. Race-condition-free is the bar for a correct one.
